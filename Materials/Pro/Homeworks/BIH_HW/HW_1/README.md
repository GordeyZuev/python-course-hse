# **BIH HW 1**

## **Утиные Истории**

**[Открыть задание](BHW-1.ipynb)**

В папке `Other` находятся готовые инструменты и открытые проверки. `duck_other.png` – фотография для упражнений и учебных опытов; `masks.npz` – общие маски потерь; `final_photo.npz` – другой повреждённый снимок и его маска, без оригинала. Откройте `BHW-1.ipynb` из этой папки.

Используйте настроенное окружение курса. В начале есть установка `numpy`, `pillow`, `matplotlib`. Пишите решения вместо `...` и `raise NotImplementedError`. После решения можно раскомментировать пример под функцией и выполнить его для самопроверки. Затем запустите готовую проверку. Повторяйте её после изменения функции. При успехе выполняется опыт с видимыми параметрами: их можно менять. В конце ноутбука есть повторная проверка всех функций. Если импорт `Other` не найден, проверьте, что ноутбук открыт из папки `HW_1` вашего репозитория.

№1–10: кадр, рамка, калибровка, карта изменений, маска и перекрашивание шапки, потери пикселей, уменьшение изображения, соседи и шаг восстановления. В начале проекта показываем повреждённую утку на микрофоне. В №11 получаем её первое восстановление. В №12–14 исследуем методы на фотографии с шапкой, где можно измерить ошибку по оригиналу. В №15 возвращаемся к утке на микрофоне и сравниваем выбранный результат с первым. Чистый оригинал этой утки студентам не выдаётся.

## **Баллы**

Десять функций дают **5 баллов**. Каждая оценивается целиком при верном результате и соблюдении правил NumPy. Открытые проверки проверяют примеры, формы, типы, неизменность входов и требуемые копии. Полные тесты у преподавателей проверяют дополнительные случаи. Допуск вещественных сравнений: `rtol=1e-7, atol=1e-8`.

Проект даёт **5 баллов**, в том числе частично:

| Задача | Баллы и результат |
| --- | --- |
| №11 | 1 – первый полный метод и восстановленная фотография |
| №12 | 12.1 – 0,5 за сравнение повреждений; 12.2 – 0,25 за карту ошибки и MAE по ней |
| №13 | 1.5 – другая идея восстановления, параметр и первый опыт |
| №14 | 1.25 – гипотеза, три настройки, сравнение методов на общих повреждениях |
| №15 | 0.5 – другой снимок без оригинала и подстройки, итог, ограничение и журнал |

Исследование проверяет ассистент. Не требуется совпадение со вторым методом преподавателя или порог ошибки. Неподтвердившаяся гипотеза может получить полный балл за корректное исследование. Короткий выбор превью в №8 нужен для обсуждения результата; отдельного порога качества нет.
