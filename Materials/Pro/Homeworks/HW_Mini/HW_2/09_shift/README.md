#### **№9. Закрыть смену. · 0.9 балла**

Смена закончилась: все заказы выданы, возникла ошибка или оператор остановил работу. В каждом случае начатую смену нужно отметить закрытой. Напишите генератор `shift(iterable, log)`, который выдаёт заказы и при завершении дописывает в список `log` строку `"закрыта"`.

```python
log = []
orders = shift(["латте", "чай"], log)
next(orders)  # -> латте
orders.close()
log           # -> ['закрыта']
```

Если дочитать очередь обычным способом, отметка появится сама:

```python
log = []
list(shift(["латте", "чай"], log))  # -> ['латте', 'чай']
log                                # -> ['закрыта']
```

**Уточнения.**

- Смена начинается при первом `next`. Закрытие до запуска не оставляет отметки; обход пустого источника оставляет.
- При исчерпании, ошибке источника, ошибке через `throw` или вызове `close()` добавьте ровно одну отметку. Ошибки должны выйти наружу.
- Выдача последнего заказа ещё не завершает обход: нужен следующий `next` или `close()`. До завершения `log` не меняется.
- Старые записи в `log` сохраняются. Повторный `close()` ничего не добавляет, а `next` после завершения вызывает `StopIteration`. Разные смены работают независимо.

## **Как это сделать.**

Обязательно поместите обход в `try` / `finally` и допишите отметку в `finally`. Внутри `finally` ничего не выдавайте через `yield`.
