#### **№10. Сценарий из файла. · 1 балл**

Ведущий читает сценарий реплику за репликой. Напишите генератор `read_lines(path)`, который выдаёт строки текстового файла по одной, убирая перевод строки в конце каждой реплики.

В этой папке уже есть [scenario.txt](scenario.txt). Откройте его: там три реплики, а между первой и второй оставлена пустая строка.

```text
Добрый вечер!

Сейчас прозвучат заявки слушателей.
До встречи!
```

После написания функции попробуйте этот код **из папки задачи**:

```python
from read_lines import read_lines

lines = read_lines("scenario.txt")
next(lines)  # -> 'Добрый вечер!'
next(lines)  # -> ''
list(lines)  # -> ['Сейчас прозвучат заявки слушателей.', 'До встречи!']
```

`list(lines)` забрал оставшиеся реплики: первые две строки мы уже прочитали через `next`.

**Уточнения.**

- Файл существует и записан в UTF-8. Путь можно передать строкой или объектом `Path`.
- Пустой файл ничего не выдаёт. Последняя строка приходит, даже если после неё нет перевода строки.
- Убирайте только завершающий `\n`. Пробелы по краям и пустые строки сохраняйте. Например, строка `"  Тише!  \n"` должна стать `"  Тише!  "`.
- До первого `next` файл не открывается. Дальше читайте по одной строке, без `read()`, `readlines()` и загрузки файла в список.
- При полном обходе, ошибке или `lines.close()` начатый генератор должен закрыть файл.

## **Как это сделать.**

Обязательно используйте встроенный `open` с `encoding="utf-8"` и конструкцию `with` внутри генератора. Обходите файловый объект по строкам, снимайте конечный `\n` и отдавайте реплику через `yield`. Оставьте параметр `newline` по умолчанию: Python сам приведёт обычные окончания строк разных систем к `\n`. `with` закроет файл при завершении; если остановились раньше конца сценария, вызовите `lines.close()`.
