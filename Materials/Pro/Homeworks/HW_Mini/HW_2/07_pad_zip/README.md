#### **№7. Гости и места. · 0.8 балла**

Есть список гостей эфира и список мест в студии. Их сопоставляют по порядку, но длины могут различаться. Напишите генератор `pad_zip(left, right, fill=None)`: он выдаёт пары до конца **обоих** источников, заполняя недостающую сторону значением `fill`.

```python
list(pad_zip(["Аня", "Боря"], ["микрофон 1"], fill="—"))
# -> [('Аня', 'микрофон 1'), ('Боря', '—')]
list(pad_zip(["Аня"], ["место 1", "место 2"]))
# -> [('Аня', 'место 1'), (None, 'место 2')]
```

**Уточнения.**

- Оба источника пусты – пар нет. Если пуст один, вся его сторона заполняется `fill`.
- `None`, ноль и значение, равное `fill`, могут быть настоящими данными. Конец определяется только по `StopIteration`.
- Для всех пропусков используется сам объект `fill`, без копирования.
- Источниками могут быть одноразовые итераторы. До первого `next` они не читаются; для каждой пары берите не больше одного элемента с каждой стороны, сначала слева.

## **Как это сделать.**

Готовая функция [`itertools.zip_longest`](https://docs.python.org/3/library/itertools.html#itertools.zip_longest) позволяет сопоставить источники разной длины и заполнить пропуски одним вызовом. В этой задаче мы пишем `pad_zip` самостоятельно для двух источников, чтобы потренировать независимую обработку их завершения. **Использовать `itertools.zip_longest` и встроенный `zip` в решении запрещено.**

Получите два итератора и напишите свой генератор. Обрабатывайте конец каждой стороны отдельно и останавливайтесь, когда закончились обе.
