#### **№4. Заставка на повторе. · 0.7 балла**

Короткая заставка приходит по частям из одноразового источника. Её нужно проиграть несколько раз. Напишите генератор `replay(iterable, times)`.

```python
parts = (part for part in ["позывной", "название станции"])
list(replay(parts, 2))
# -> ['позывной', 'название станции', 'позывной', 'название станции']
```

Одноразовый источник нельзя обойти заново, поэтому для повторов понадобятся сохранённые элементы:

```python
list(replay(["позывной"], 3))  # -> ['позывной', 'позывной', 'позывной']
list(replay(["позывной"], 0))  # -> []
```

**Уточнения.**

- `times` – целое число. Ноль даёт пустой генератор; отрицательное значение вызывает `ValueError` при начале обхода. Источник в этих случаях не трогайте, даже через `iter`.
- Источник конечный и небольшой. До первого `next` он не читается; при положительном `times` первый `next` сохраняет его **целиком**, затем начинается выдача.
- Пустой источник ничего не выдаёт при любом положительном `times`.
- Сохраняйте порядок и сами объекты, без копирования. Исходный итератор исчерпывается; переданный список не меняется.

## **Как это сделать.**

Готовая функция [`itertools.cycle`](https://docs.python.org/3/library/itertools.html#itertools.cycle) позволяет организовать повтор элементов по кругу одним вызовом. В этой задаче мы пишем свой вариант – `replay` – самостоятельно, чтобы разобраться, как сохранить одноразовый источник для повторных проходов. **Использовать `itertools.cycle` в решении запрещено.**

У нашей версии два отличия: повторов ровно `times`, а весь конечный источник сохраняется перед первым результатом. Библиотечный `cycle` выдаёт элементы уже при первом проходе и повторяет непустую последовательность бесконечно.

Используйте генератор и локальный список для сохранённых элементов. После проверки `times` один раз заполните список и выдайте его содержимое `times` раз.
