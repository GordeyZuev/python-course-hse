#### **№11. Сохранить и прочитать журнал. · 1.1 балла**

Редактор собрал длительности блоков эфира: 3, 4 и 2 минуты. Их нужно сохранить в журнал, а затем получить общую длительность по сохранённым строкам. Напишите функцию `save_total(path, numbers)`: она записывает числа в файл, читает его с начала и возвращает сумму прочитанных чисел.

Так мы потренируем передачу данных через файл: один этап сохраняет журнал, другой читает его и строит сводку. В этой задаче оба этапа выполняет одна функция.

```python
save_total("durations.txt", [3, 4, 2])  # -> 9
```

После вызова появится файл `durations.txt`. Откройте его – внутри должно быть:

```text
3
4
2
```

Каждое число занимает отдельную строку, после последнего тоже стоит перевод строки.

**Ещё примеры:**

```python
save_total("durations.txt", [10, -3, 0])  # -> 7; старый журнал заменён
# Теперь в файле: "10\n-3\n0\n"

save_total("durations.txt", [])  # -> 0; файл теперь пуст
```

Отрицательное число означает корректировку длительности.

**Уточнения.**

- `numbers` – конечный список целых чисел. Результат – целое число.
- Создайте файл, если его ещё нет, или полностью замените прежнее содержимое. Ноль записывается как `0`.
- Путь можно передать строкой или объектом `Path`; папка для файла уже существует.
- После возврата функции все открытые файлы должны быть закрыты.

## **Как это сделать.**

Обязательно используйте встроенный `open` и `with` для обоих этапов. Сначала запишите числа в UTF-8, добавляя к каждому `\n`; при записи задайте `newline="\n"`, чтобы формат файла был одинаковым на разных системах. Затем откройте файл на чтение, тоже в UTF-8, преобразуйте строки через `int` и накопите сумму. Можно использовать один файл в режиме `"w+"`, но после записи нужно вернуться к началу через `seek(0)`.
