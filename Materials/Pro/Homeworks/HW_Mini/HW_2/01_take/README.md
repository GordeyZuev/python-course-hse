#### **№1. Первые заявки. · 0.5 балла**

До конца эфира осталось место только для `n` заявок слушателей. Напишите функцию `take(n, iterable)`, которая забирает первые `n` элементов из источника и возвращает список. Если заявок меньше, заберите все доступные.

```python
take(2, ["Аня", "Боря", "Вера"])  # -> ['Аня', 'Боря']
take(5, ["Аня"])                  # -> ['Аня']
```

**Уточнения.**

- `n` – целое число. При `n = 0` верните `[]`, при отрицательном `n` поднимите `ValueError`. В обоих случаях не обращайтесь к источнику, даже через `iter`.
- Пустой источник даёт `[]`. В остальных случаях заберите не больше `n` элементов: лишний `next` съел бы чужую заявку.
- Источником может быть список или одноразовый итератор. Возвращайте сами полученные объекты, без копирования.

## **Как это сделать.**

Готовая функция [`itertools.islice`](https://docs.python.org/3/library/itertools.html#itertools.islice) позволяет коротко записать выборку первых элементов; её результат можно превратить в список. В этой задаче мы пишем `take` самостоятельно, чтобы разобраться, как ограничить чтение источника. **Использовать `itertools.islice` в решении запрещено.**

Сначала проверьте `n`. Затем получите итератор через `iter` и забирайте элементы через `next`, обрабатывая `StopIteration`. Верните собранный список.
