#### **№5. Переходы между треками. · 0.8 балла**

Редактор проверяет соседние треки: хорошо ли звучит переход из одного в другой? Для пары нужен отрезок длины 2, для проверки короткой подборки – длины 3. Напишите генератор `window(iterable, n)`, который выдаёт такие отрезки кортежами и сдвигается каждый раз на один элемент.

```python
list(window(["джаз", "соул", "фанк"], 2))
# -> [('джаз', 'соул'), ('соул', 'фанк')]
list(window([1, 2, 3, 4], 3))  # -> [(1, 2, 3), (2, 3, 4)]
```

Окно выдаётся, только когда в него набралось достаточно элементов:

```python
list(window(["джаз", "соул"], 3))  # -> []
list(window(["джаз", "соул"], 1))  # -> [('джаз',), ('соул',)]
```

**Уточнения.**

- `n` – целое число. При `n < 1` поднимите `ValueError` при начале обхода, не обращаясь к источнику.
- Выдавайте только полные окна. Пустой или слишком короткий источник ничего не даёт; длина ровно `n` даёт одно окно.
- До первого `next` источник не читается. Первое окно требует `n` элементов, каждое следующее – одного нового. Исходные объекты внутри окон не копируются.

## **Как это сделать.**

Готовая функция [`itertools.pairwise`](https://docs.python.org/3/library/itertools.html#itertools.pairwise) позволяет получить соседние пары одним вызовом – это окна длины 2. В этой задаче мы пишем `window` самостоятельно для любой положительной длины окна, чтобы потренировать хранение последних элементов. **Использовать `itertools.pairwise` в решении запрещено.**

Используйте генератор и буфер текущего окна: список или `deque`. Храните только `n` последних элементов и отдавайте новый кортеж при каждом сдвиге. Это скользящее окно – отрезок фиксированной длины, двигающийся по последовательности.
