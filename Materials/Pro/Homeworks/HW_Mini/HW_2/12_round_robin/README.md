#### **№12. Каждому по очереди. · 1.2 балла**

Заявки приходят из нескольких городов. Если сначала вычитать всю очередь одного города, остальные будут ждать слишком долго. Напишите генератор `round_robin(*iterables)`, который берёт по одному элементу из каждого источника по кругу.

```python
list(round_robin(["М1", "М2", "М3"], ["К1"], ["Т1", "Т2"]))
# -> ['М1', 'К1', 'Т1', 'М2', 'Т2', 'М3']
```

> Round robin – круговой обход: каждому участнику по очереди достаётся один ход. Здесь ход – выдача одного элемента. Такой принцип используют и при распределении работы между очередями.

**Уточнения.**

- Порядок источников задаётся аргументами. После последнего живого источника начинайте следующий круг с первого живого.
- Исчерпанные источники выбывают. Пустые не оставляют пропусков. Когда источников больше нет, генератор заканчивается.
- Без аргументов результат пуст.
- До первого `next` элементы не читаются. Каждый запрос берёт только ближайший доступный элемент; остальные источники ждут своего хода.
- Источники могут быть одноразовыми итераторами. Элементы выдаются как есть, в том числе вложенные списки.

## **Как это сделать.**

Храните активные итераторы в списке или очереди и выдавайте элементы через `yield`. При `StopIteration` убирайте источник из дальнейших кругов, не пропуская его соседа. Здесь соединяются приёмы из задач про последовательный обход и сопоставление двух источников.
