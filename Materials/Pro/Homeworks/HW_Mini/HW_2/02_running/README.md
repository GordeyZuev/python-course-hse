#### **№2. Хронометраж эфира. · 0.6 балла**

Треки длятся 3, 4 и 2 минуты. Редактору нужно знать, на какой минуте закончится каждый: 3, 7 и 9. Напишите `running(iterable, func=None)` – генератор накопленных результатов.

Первый элемент выходит как есть. Для каждого следующего результат равен `func(накоплено, новый_элемент)`. Если `func` не передана или равна `None`, складывайте значения.

```python
list(running([3, 4, 2]))  # -> [3, 7, 9]
list(running([3, 4, 2], max))  # -> [3, 4, 4]
```

Второй вызов показывает самую большую длительность среди уже просмотренных треков.

**Уточнения.**

- Пустой источник ничего не выдаёт. Для одного элемента `func` вообще не вызывается.
- По умолчанию работаем с числами, включая ноль и отрицательные. С пользовательской функцией элементы могут быть другими.
- `func` вызывается ровно один раз на каждый элемент после первого.
- До первого `next` источник не читается; каждый следующий результат требует только одного нового элемента.

**Пример с порядком аргументов:**

```python
def subtract(total, correction):
    return total - correction

list(running([10, 3, 1], subtract))  # -> [10, 7, 6]
```

## **Как это сделать.**

Готовая функция [`itertools.accumulate`](https://docs.python.org/3/library/itertools.html#itertools.accumulate) позволяет получить накопленные результаты одним вызовом. В этой задаче мы пишем `running` самостоятельно, чтобы потренировать хранение и обновление результата между выдачами генератора. **Использовать `itertools.accumulate` в решении запрещено.**

Напишите генератор с `yield`. Первое значение станет накопленным результатом; затем обновляйте его перед каждой выдачей. Не собирайте источник целиком: результат нужен уже после первого элемента.
