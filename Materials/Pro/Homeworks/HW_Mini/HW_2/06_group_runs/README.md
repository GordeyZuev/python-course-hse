#### **№6. Серии событий. · 0.8 балла**

В журнале станции подряд повторяется одно и то же событие: «сигнал пропал», «сигнал пропал», затем «сигнал восстановлен». Для разбора удобно собрать соседние повторы в серии. Напишите генератор `group_runs(iterable)`, который выдаёт каждую серию отдельным списком.

```python
list(group_runs(["сбой", "сбой", "норма", "сбой"]))
# -> [['сбой', 'сбой'], ['норма'], ['сбой']]
```

Ещё пример: одинаковые числа попадают в одну серию, только когда стоят рядом.

```python
list(group_runs([1, 1, 2, 2, 2, 1]))  # -> [[1, 1], [2, 2, 2], [1]]
list(group_runs([7]))                 # -> [[7]]
```

Последняя единица начинает новую серию: между ней и первой парой были двойки.

**Уточнения.**

- Сравнивайте соседей через `==`.
- Пустой источник ничего не выдаёт. Последняя серия тоже входит в результат.
- Сохраняйте сами объекты: `1` и `True` равны и входят в одну серию, но `True` должен остаться `True`. Элементами могут быть и списки.
- До первого `next` источник не читается. Чтобы узнать конец серии, разрешено прочитать первый элемент следующей серии. Дальше заранее не читайте.
- Каждая выданная серия – отдельный список: продолжение обхода не меняет прежние результаты.

## **Как это сделать.**

Готовая функция [`itertools.groupby`](https://docs.python.org/3/library/itertools.html#itertools.groupby) позволяет сгруппировать соседние равные значения: она выдаёт пары «значение и итератор группы». В этой задаче мы пишем `group_runs` самостоятельно и возвращаем каждую серию отдельным списком, чтобы разобраться, как находить границы серий при обходе. **Использовать `itertools.groupby` в решении запрещено.**

Напишите генератор, который хранит текущую серию. Пока следующий элемент равен предыдущему, добавляйте его. При смене значения отдайте собранный список и начните новый; после конца источника отдайте оставшуюся серию.
