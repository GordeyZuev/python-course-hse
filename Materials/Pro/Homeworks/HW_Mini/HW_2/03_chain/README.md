#### **№3. Плейлисты подряд. · 0.7 балла**

Сначала играет подборка ведущего, затем заявки слушателей, затем ночной плейлист. Напишите генератор `chain(*iterables)`, который выдаёт содержимое источников в этом порядке.

```python
list(chain(["вступление"], [], ["ночь", "город"]))
# -> ['вступление', 'ночь', 'город']
```

**Уточнения.**

- Без источников результат пуст. Пустые источники пропускаются.
- До первого `next` ни один источник не читается. Следующий источник начинает отдавать элементы только после завершения предыдущего.
- Можно смешивать списки и одноразовые итераторы.
- Вложенные списки остаются отдельными элементами, без распаковки: `list(chain([1, [2, 3]], [4]))` даёт `[1, [2, 3], 4]`.

## **Как это сделать.**

Готовая функция [`itertools.chain`](https://docs.python.org/3/library/itertools.html#itertools.chain) позволяет соединить несколько источников одним вызовом. В этой задаче мы пишем `chain` самостоятельно, чтобы потренировать последовательный обход через `yield from`. **Использовать `itertools.chain`, в том числе `chain.from_iterable`, в решении запрещено.**

Обязательно используйте `yield from`: пройдите по источникам и последовательно передайте обход каждому из них.
