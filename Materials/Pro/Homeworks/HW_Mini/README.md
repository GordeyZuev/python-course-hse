## **Домашние работы Pro.**

Сдать до 01.11.2026 23:59 (GMT+3). Один срок на весь `HW_Mini`.

Две работы после двух первых пар.

`HW 1` – функции, замыкания, декораторы. Здесь вы тренируете подпись вызова, свою память функции и обёртку вокруг чужой функции. Это закрывает пары `Funcs – 1` и `Funcs – 2`.

`HW 2` – итераторы, генераторы и файлы. Здесь вы тренируете обход, который можно остановить, склеить и повторить, и чтение с диска, которое не держит файл целиком. Это закрывает пары `Iterators – 1` и `Generators`.

У каждой работы потолок 10 баллов. Бонус прибавляется к обязательным, но итог не поднимается выше 10: берётся меньшее из 10 и суммы. Задача засчитывается целиком или даёт 0.

## **Среда с нуля.**

Нужен Python 3.10 или новее. Виртуальное окружение создаётся в этой папке.

### **macOS и Linux.**

На macOS системный `/usr/bin/python3` – заглушка, нужен установленный интерпретатор.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### **Windows.**

```bash
py -3 -m venv .venv
```

Если `py` нет, создайте окружение так: `python -m venv .venv`.

```bash
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## **Как прогнать тесты.**

Все задачи, из этой папки:

```bash
pytest
```

Одна задача из её папки:

```bash
python test.py
```

Одна задача из этого корня, на примере эфирной строки:

```bash
pytest HW_1/01_line/test.py
```

## **Отчёт баллов.**

`grade.py` лежит в `Other/tools/`. Команды ниже запускайте из корня репозитория курса: активируете окружение этой папки и запускаете грейдер. Он запускает каждый `test.py` отдельным процессом и не подменяет файлы решения. Код 0 – полные баллы задачи, иначе 0. По `HW_1` и `HW_2` отдельно печатаются обязательные, бонусы и итог с потолком 10.

### **macOS и Linux.**

```bash
source Materials/Pro/Homeworks/HW_Mini/.venv/bin/activate
python Other/tools/grade.py
```

### **Windows.**

```bash
.\Materials\Pro\Homeworks\HW_Mini\.venv\Scripts\activate
python Other/tools/grade.py
```
