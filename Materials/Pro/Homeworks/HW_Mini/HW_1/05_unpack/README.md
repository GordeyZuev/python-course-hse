#### **№5. Распаковка. · 1 балл**

**1 балл.**

Под ёлкой лежат коробки. В коробке может лежать подарок или ещё одна коробка. Вам необходимо написать функцию `unpack(boxes)`, которая будет выкладывать все подарки в один плоский ряд, слева направо, доставая подарки изнутри каждой коробки.

Коробка – список. Подарок – строка. Пустая коробка ничего не добавляет в ряд. Строка – один подарок целиком, не набор букв. Пустая строка тоже подарок – к примеру, открытка без текста (и такое бывает).

В тестах внутри коробок только строки и списки.

```python
unpack([])                                      # -> []
unpack(["мяч", ["кубик", ["конфеты"]], "книга"])  # -> ['мяч', 'кубик', 'конфеты', 'книга']
unpack(["аб"])                                  # -> ['аб']
unpack([[], "мяч", [[]]])                       # -> ['мяч']
unpack([""])                                    # -> ['']
unpack([[["бант"]]])                            # -> ['бант']
```

## **Как это сделать.**

Рекомендуем рекурсию: вложенную коробку можно разобрать тем же способом, что и внешнюю. Идите слева направо: строку добавляйте в результат целиком, а вложенный список снова передавайте `unpack`. Пустой список ничего не добавляет. Рекурсия здесь не обязательна: можно выбрать другой способ, который сохраняет порядок подарков.
