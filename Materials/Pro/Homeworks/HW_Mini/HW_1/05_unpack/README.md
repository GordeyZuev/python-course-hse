#### **№5. Распаковка. · 1 балл**

**1 балл.**

Под ёлкой коробки. В коробке лежит подарок или ещё одна коробка. `unpack(boxes)` выкладывает все подарки в один ряд, слева направо, и заходит внутрь каждой коробки.

Коробка – список. Подарок – строка. Пустая коробка ничего не добавляет в ряд. Строка – один подарок целиком, не набор букв. Пустая строка тоже подарок: открытка без текста.

В тестах внутри коробок только строки и списки.

```python
unpack([])                                      # -> []
unpack(["мяч", ["кубик", ["конфеты"]], "книга"])  # -> ['мяч', 'кубик', 'конфеты', 'книга']
unpack(["аб"])                                  # -> ['аб']
unpack([[], "мяч", [[]]])                       # -> ['мяч']
unpack([""])                                    # -> ['']
unpack([[["бант"]]])                            # -> ['бант']
```

## **Как это сделать.**

Выкладывайте подарки рекурсией. Дно – пустой список: из него нечего добавить. Вложенный список снова отдаёте `unpack`.
