#### **№3. Палиндром. · 0.5 балла**

**0.5 балла.**

> Палиндром – это число, буквосочетание, слово или текст, который одинаково читается в обоих направлениях: слева направо и справа налево.

Напишите функцию `is_palindrome(text)`, которая возвращает `True`, если строка – палиндром, и `False` в противном случае. Регистр учитывается: маленькая и большая буквы различны. Пробел – самостоятельный символ.

Пустая строка и строка из одного символа считаются палиндромами.

```python
is_palindrome("")        # -> True
is_palindrome("а")       # -> True
is_palindrome("аа")      # -> True
is_palindrome("аб")      # -> False
is_palindrome("казак")   # -> True
is_palindrome("Казак")   # -> False
is_palindrome("а а")     # -> True
is_palindrome("аб а")    # -> False
```



## **Как это сделать.**

Рекомендуем попробовать рекурсию, чтобы потренировать базовый и рекурсивный случаи. Базовый случай – пустая строка или один символ. У более длинной строки сравните крайние символы; если они равны, продолжите проверку для части между ними. Рекурсия здесь не обязательна: можно выбрать другой способ, который соблюдает условие.
