#### **№3. Палиндром. · 0.5 балла**

**0.5 балла.**

`is_palindrome(text)` говорит, читается ли строка одинаково слева направо и справа налево. Регистр и пробелы не выбрасываются: сравниваются сами символы.

Пустая строка и один символ – палиндром. У более длинной строки совпадают первый и последний символы, а середина – тоже палиндром.

```python
is_palindrome("")        # -> True
is_palindrome("а")       # -> True
is_palindrome("аа")      # -> True
is_palindrome("аб")      # -> False
is_palindrome("казак")   # -> True
is_palindrome("Казак")   # -> False
is_palindrome("а а")     # -> True
is_palindrome("аб а")    # -> False
```

## **Как это сделать.**

Проверяйте строку рекурсией. Дно – короткая строка: пустая или из одного символа. Более длинную сводите к тому же вызову на более короткой.
