#### **№9. Декоратор-вредитель. · 0.5 балла**

**0.5 балла.**

`vandal` оборачивает функцию и переворачивает её `docstring`. Результат вызова остаётся прежним.

- Декоратор без параметра. Украшение само функцию не вызывает.
- Позиционные и именованные аргументы доходят до тела. Возврат тот же, включая `None` и `0`. Исключение выходит как есть.
- `__name__` исходной функции сохраняется. Для этого подходит `functools.wraps`. После `wraps` символы `docstring` идут с конца к началу: `"эфир"` становится `"рифэ"`.
- Если `docstring` нет (`None`), снаружи остаётся `None`. Пустая строка `""` остаётся `""`. Пробелы и переводы строки – тоже символы, их не выкидывают.
- Две функции портят документацию порознь.

```python
@vandal
def say(text):
    """эфир"""
    return text

say.__doc__   # -> рифэ
say("ночь")   # -> ночь
say.__name__  # -> say
```

```python
@vandal
def give(value):
    return value

give(None)    # -> None
give(0)       # -> 0
give.__doc__  # -> None
```

## **Как это сделать.**

Сначала `functools.wraps` копирует имя и документацию. Потом разверните уже скопированный `docstring`. `None` не трогайте.
