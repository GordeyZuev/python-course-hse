#### **№9. Декоратор-вредитель. · 0.5 балла**

**0.5 балла.**

Представим, что мы посмотрели мультфильм «Гадкий Я» и теперь хотим что-то поломать. Кандидаты для этого – функции. Мы хотим написать декоратор, который будет переворачивать `docstring` функции. Напишите декоратор `vandal`, который оборачивает функцию и переворачивает её `docstring`. Результат вызова остаётся прежним.

**Уточнения.**

- Уже скопированный `docstring` переверните: `"эфир"` становится `"рифэ"`.
- Если `docstring` нет (`None`), снаружи остаётся `None`. Пустая строка `""` остаётся `""`. Пробелы и переводы строки тоже символы, их не выкидывают.

Возьмите `functools.wraps`, чтобы скопировать имя и документацию исходной функции на обёртку. Имя `__name__` сохраните, а скопированный `__doc__` переверните по правилам выше.

```python
@vandal
def say(text):
    """эфир"""
    return text

say.__doc__   # -> рифэ
say("ночь")   # -> ночь
say.__name__  # -> say
```

```python
@vandal
def give(value):
    return value

give(None)    # -> None
give(0)       # -> 0
give.__doc__  # -> None
```

## **Как это сделать.**

Сначала `functools.wraps` копирует имя и документацию. Потом переверните уже скопированный `docstring`. `None` и пустую строку не трогайте. Вызов, аргументы и ошибку не меняйте.
