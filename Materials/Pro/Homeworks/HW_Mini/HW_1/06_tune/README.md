#### **№6. Одна частота. · 1 балл**

**1 балл.**

На весь модуль одна частота. В этом файле оставьте рядом имя `FREQ` и две функции, `listen` и `tune`. В шаблоне `FREQ` равна `100`. Обе смотрят в это имя, а не в память одного вызова.

`listen()` возвращает частоту, которая лежит в модуле сейчас. Сама она `FREQ` не меняет.

`tune(delta)` прибавляет `delta` к частоте модуля и возвращает то, что получилось. Следующий `listen` и следующий `tune` видят уже новую частоту.

Снаружи в `FREQ` могут записать другое число. Оба вызова после этого работают с ним, а не со старой сотней.

Читать имя модуля можно без объявления. Запись в это имя из функции без `global` создаёт другое, локальное имя, и модуль не меняется. Как пишут в имя модуля: [The global statement](https://docs.python.org/3/reference/simple_stmts.html#the-global-statement).

Порогов нет: частота может стать нулём и уйти ниже нуля.

```python
listen()     # -> 100
tune(5)      # -> 105
listen()     # -> 105
tune(0)      # -> 105
tune(-3)     # -> 102

FREQ = 90
listen()     # -> 90
tune(-3)     # -> 87

FREQ = 4
tune(-4)     # -> 0
listen()     # -> 0

FREQ = 0
tune(-5)     # -> -5
listen()     # -> -5
```

## **Как это сделать.**

`global` пишите только в `tune`: там частота модуля меняется. `listen` имя не объявляет, она просто читает `FREQ`.
