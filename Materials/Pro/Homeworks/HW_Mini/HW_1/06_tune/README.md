#### **№6. Одна частота. · 1 балл**

**1 балл.**

На станции частота – одно число. Его выставляют одной ручкой: повернули ручку, число стало другим. В файле это число называется `FREQ`. Сначала там записано `FREQ = 100`.

Напишите две функции рядом с этим именем: `listen()` и `tune(delta)`. Обе смотрят в одно и то же число в файле.

`listen()` возвращает частоту, которая лежит в `FREQ` сейчас, и само число не меняет. `tune(delta)` прибавляет `delta` к `FREQ` и возвращает то, что получилось.

**Уточнения.**

- После `tune(5)` частота уже `105`. Следующий `listen()` возвращает `105`, а не `100`. Следующий `tune(-3)` прибавляет к `105` и возвращает `102`.
- `tune(0)` частоту не меняет. Частота может стать `0` и уйти ниже нуля.
- Снаружи в `FREQ` могут записать другое число, например `FREQ = 90`. Обе функции после этого работают с `90`, а не со старой сотней.
- Прочитать `FREQ` из функции можно сразу. Чтобы записать в него из `tune`, нужен `global`. Без `global` появится другое, локальное имя, и число в файле не изменится. Как пишут в имя модуля: [The global statement](https://docs.python.org/3/reference/simple_stmts.html#the-global-statement).

**Примеры:**

```python
listen()     # -> 100
tune(5)      # -> 105
listen()     # -> 105
tune(0)      # -> 105
tune(-3)     # -> 102

FREQ = 90
listen()     # -> 90
tune(-3)     # -> 87

FREQ = 4
tune(-4)     # -> 0
listen()     # -> 0

FREQ = 0
tune(-5)     # -> -5
listen()     # -> -5
```

## **Как это сделать.**

`listen` только читает `FREQ` и ничего не объявляет. В `tune` напишите `global`, прибавьте `delta` к `FREQ` и верните новое число.
