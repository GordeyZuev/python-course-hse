#### **№11. Сколько раз вызвали. · 0.5 балла**

**0.5 балла.**

Нужно знать, сколько раз функцию реально вызвали, не меняя её тело. `counted` оборачивает функцию. Результат остаётся прежним. На обёртке живёт `calls`.

- До первого вызова `calls == 0`. Само украшение функцию не вызывает.
- Успешный вызов прибавляет 1.
- Падение тоже прибавляет 1. Ошибка летит дальше тем же типом и с тем же текстом. В тесте это `ValueError`. Что такое исключение и как его поднимают: [Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html#raising-exceptions).
- Позиционные и именованные аргументы доходят до тела.
- У двух функций два разных счётчика.
- Снаружи видны `__name__` и `__doc__` исходной функции. Для этого подходит `functools.wraps`.

```python
@counted
def ready():
    return "готово"

ready.calls  # -> 0
ready()      # -> готово
ready.calls  # -> 1
ready()
ready.calls  # -> 2
```

```python
@counted
def boom():
    raise ValueError("сломалось")

boom()         # ValueError: сломалось
boom.calls     # -> 1
```

## **Как это сделать.**

Обёртка держит число вызовов на себе, в атрибуте `calls`, с нуля. Сначала прибавьте единицу, потом позовите исходную функцию и верните её результат. Падение тоже уже посчитано, ошибку не подменяйте. `functools.wraps` оставляет имя и документацию.
