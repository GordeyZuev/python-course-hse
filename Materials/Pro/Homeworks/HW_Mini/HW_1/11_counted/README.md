#### **№11. Сколько раз вызвали. · 0.5 балла**

**0.5 балла.**

Представьте, что вы создали функцию и хотите понимать, сколько именно раз её запускали. Но менять для этого тело функции вы не хотите. Именно здесь и проявляется суть декораторов. Напишите декоратор `counted`, который будет содержать счётчик вызовов, который можно узнать через `calls`.

**Уточнения.**

- До первого вызова `calls == 0`. Само декорирование функцию не вызывает.
- Любой вызов прибавляет 1, в том числе падение. Если это падение – ошибка летит дальше тем же типом и с тем же текстом. [Как обрабатывать и выбрасывать исключения?](https://docs.python.org/3/tutorial/errors.html#raising-exceptions).
- Позиционные и именованные аргументы доходят до тела. Результат вызова остаётся прежним.
- Общая `global` переменная здесь не подойдёт: счётчик живёт на самой обёртке.

`__name__` и `__doc__` остаются от исходной функции. Возьмите `functools.wraps`. Две обёрнутые функции не делят счётчик.

```python
@counted
def ready():
    return "готово"

ready.calls  # -> 0
ready()      # -> готово
ready.calls  # -> 1
ready()
ready.calls  # -> 2
```

```python
@counted
def boom():
    raise ValueError("сломалось")

boom()         # ValueError: сломалось
boom.calls     # -> 1
```

## **Как это сделать.**

Обёртка держит число вызовов на себе, в атрибуте `calls`, с нуля. Сначала прибавьте единицу, потом позовите исходную функцию и верните её результат. Падение тоже уже посчитано, ошибку не подменяйте.
