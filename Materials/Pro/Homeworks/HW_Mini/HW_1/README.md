## **Зачем это ДЗ.**

Здесь вы тренируете подпись вызова, свою память функции и обёртку вокруг чужой функции. Проверка – тесты в папке задачи. Потолок – 10 баллов.

## **Баллы.**

Все задачи вместе дают 12 баллов: обязательные 10 и бонусы 2. Итог не поднимается выше 10: берётся меньшее из 10 и суммы. Задача засчитывается целиком или даёт 0.

Папки лежат по порядку сложности.

1. `01_line` – 0.5 балла
2. `02_ask` – 0.5 балла
3. `03_palindrome` – 0.5 балла
4. `04_polish` – 0.5 балла
5. `05_unpack` – 1 балл
6. `06_tune` – 1 балл
7. `07_make_fader` – 1 балл
8. `08_partial` – 1 балл
9. `09_vandal` – 0.5 балла
10. `10_shabbat` – бонус, 1 балл
11. `11_counted` – 0.5 балла
12. `12_html` – 1 балл
13. `13_fragile` – 1 балл
14. `14_memoize` – 1 балл
15. `15_silent` – бонус, 1 балл

Бонусы в обязательные 10 баллов не входят: `10_shabbat` и `15_silent`, по 1 баллу. Ими можно добрать до 2 баллов, если обязательная задача не вышла. В списке выше они стоят по сложности.

## **Как собрать среду.**

Нужен Python 3.10 или новее. Окружение и `requirements.txt` лежат в корне `HW_Mini`. Команды этого раздела запускайте оттуда.

### **macOS и Linux.**

На macOS системный `/usr/bin/python3` – заглушка, нужен установленный интерпретатор.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### **Windows.**

```bash
py -3 -m venv .venv
```

Если `py` нет, создайте окружение так: `python -m venv .venv`.

```bash
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## **Как запустить тесты.**

Все задачи этой части, из корня `HW_Mini`:

```bash
pytest HW_1
```

Одна задача из её папки:

```bash
python test.py
```

Одна задача из корня `HW_Mini`:

```bash
pytest HW_1/01_line/test.py
```

## **Отчёт баллов.**

`grade.py` лежит в `Other/tools/`. Команды ниже запускайте из корня репозитория курса: активируете окружение `HW_Mini` и запускаете грейдер. Он считает обе домашки и не подменяет файлы решения. Код 0 – полные баллы задачи, иначе 0.

### **macOS и Linux.**

```bash
source Materials/Pro/Homeworks/HW_Mini/.venv/bin/activate
python Other/tools/grade.py
```

### **Windows.**

```bash
.\Materials\Pro\Homeworks\HW_Mini\.venv\Scripts\activate
python Other/tools/grade.py
```
