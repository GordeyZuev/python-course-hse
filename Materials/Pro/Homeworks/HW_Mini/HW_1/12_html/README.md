#### **№12. Страница эфира. · 1 балл**

**1 балл.**

Функция возвращает текст блока. `html(tag)` надевает на него элемент: открывающий тег, текст, закрывающий тег.

Несколько строк `@` вкладывают элементы. Ближняя к `def` применяется первой: `@html("div")` над `@html("p")` – это `html("div")(html("p")(func))`.

- Тег – строка как есть. Имя HTML не проверяется.
- Символы `<` и `>` внутри текста не экранируются.
- Пустой тег даёт `<>текст</>`. Пустой текст оставляет теги без символов между ними.
- Аргументы доходят до нижней функции. В момент украшения тело не вызывается.
- У внешней обёртки – `__name__` и `__doc__` нижней функции. Для этого подходит `functools.wraps`.

```python
@html("p")
def line():
    return "ночь"

line()  # -> <p>ночь</p>
```

```python
@html("div")
@html("p")
def line():
    return "ночь"

line()  # -> <div><p>ночь</p></div>
```

```python
@html("")
def blank():
    return "ночь"

blank()  # -> <>ночь</>

@html("p")
def raw():
    return "a < b > c"

raw()  # -> <p>a < b > c</p>
```

## **Как это сделать.**

`html(tag)` возвращает декоратор. Обёртка подставляет результат между тегами. Цепочка из нескольких `@` получается сама: ближний к `def` срабатывает первым.
