#### **№12. Страница эфира. · 1 балл**

**1 балл.**

Представим, что функция возвращает какой-то текст (или блок текста). И вы хотите этот блок обернуть в какой-то заголовок / любой другой `html-tag`. В этой задаче необходимо реализовать декоратор `html(tag)`, который надевает на этот блок текста элемент: открывающий тег, текст, закрывающий тег.

> `HTML-тег` – пометка в тексте, которая говорит браузеру, что это за объект перед ним и как его показать. Например, `<h1>Привет</h1>` – это заголовок. Тег нужен для того, чтобы определить, какая роль у текста – заголовок / абзац / ссылка / жирный шрифт.

**Уточнения.**

- Тег – просто строка как есть. Валидность HTML мы не проверяем.
- Символы `<` и `>` внутри текста не экранируются.
- Пустой тег даёт `<>текст</>`. Пустой текст оставляет теги без символов между ними: `<p></p>`.
- Аргументы доходят до нижней функции. В момент декорирования тело не вызывается.

`__name__` и `__doc__` остаются от исходной функции. Возьмите `functools.wraps`. Две обёрнутые функции не делят обёртку.

```python
@html("p")
def line():
    return "ночь"

line()  # -> <p>ночь</p>
```

```python
@html("div")
@html("p")
def line():
    return "ночь"

line()  # -> <div><p>ночь</p></div>
```

```python
@html("")
def blank():
    return "ночь"

blank()  # -> <>ночь</>

@html("p")
def raw():
    return "a < b > c"

raw()  # -> <p>a < b > c</p>
```

## **Как это сделать.**

`html(tag)` возвращает декоратор. Обёртка зовёт нижнюю функцию и подставляет результат между тегами. Цепочка из нескольких `@` получается сама: ближний к `def` срабатывает первым.
