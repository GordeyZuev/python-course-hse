#### **№10. Шаббат. · Бонус · 1 балл**

**Бонус. 1 балл.**

Напишите декоратор `shabbat`. Пока исходная функция работает, обёртка вызывает её и проверяет возвращённое значение. Как только функция вернула строку длины 6, обёртка возвращает `"Отдых"` уже в этом вызове и запоминает остановку. Каждый следующий вызов сразу возвращает `"Отдых"`, не вызывая исходную функцию.

До этого момента все возвращаемые значения должны возвращаться как есть: строка другой длины, число, `None`, список, `bytes`. Число `6` остановку не включает. Шесть пробелов – строка длины 6.

До остановки ошибка выходит как есть и остановку не включает, обрабатывать её не нужно. После остановки тело исходной функции больше не запускается: наружу идёт `"Отдых"`, даже если переданные аргументы привели бы в нём к ошибке. Здесь пригодится приём:

> Early exit (из функции) – паттерн программирования, при котором функция завершается как можно раньше, как только становится ясен результат, вместо того чтобы оборачивать всю логику в глубоко вложенные `if`/`else`.

Аргументы, в том числе по имени, доходят до функции, пока она ещё работает. В момент декорирования функция не вызывается. `__name__` и `__doc__` остаются от исходной функции. Возьмите `functools.wraps`. Две обёрнутые функции не делят остановку.


```python
@shabbat
def say(text):
    return text

say("ночь")      # -> ночь
say(6)           # -> 6
say("работа")    # -> Отдых
say("утро")      # -> Отдых
say("день")      # -> Отдых
```

```python
@shabbat
def spaces(text):
    return text

spaces("      ")  # -> Отдых
spaces("ночь")    # -> Отдых
```

## **Как это сделать.**

Флаг живёт в замыкании, сначала он опущен. Пока флаг опущен, зовите функцию. Вернула строку `str` длины 6 – поднимите флаг и верните `"Отдых"`. Флаг уже поднят – сразу `"Отдых"`, функцию не зовите.
