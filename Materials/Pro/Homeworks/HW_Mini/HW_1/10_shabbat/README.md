#### **№10. Шаббат. · Бонус · 1 балл**

**Бонус. 1 балл.**

`shabbat` оборачивает функцию. Она работает, пока не вернёт строку длины 6. С этого вывода наружу идёт `"Отдых"`, и каждый следующий вызов тоже возвращает `"Отдых"`.

До этого всё выходит как есть: строка другой длины, число, `None`, список, `bytes`. Число `6` функцию не останавливает.

Ошибка выходит как есть и остановку не включает. Когда остановка уже случилась, функция не вызывается: наружу идёт `"Отдых"`, даже если этот вызов упал бы. Аргументы, в том числе по имени, доходят до функции, пока она ещё работает. Украшение само её не вызывает. Снаружи видны `__name__` и `__doc__`. Для этого подходит `functools.wraps`. Две обёрнутые функции не делят остановку.

```python
@shabbat
def say(text):
    return text

say("ночь")      # -> ночь
say(6)           # -> 6
say("работа")    # -> Отдых
say("утро")      # -> Отдых
say("день")      # -> Отдых
```

```python
@shabbat
def spaces(text):
    return text

spaces("      ")  # -> Отдых
spaces("ночь")    # -> Отдых
```

## **Как это сделать.**

Флаг в замыкании, сначала он не стоит. Пока флаг снят, зовите функцию. Вернула строку длины 6 – поднимите флаг и верните `"Отдых"`. Флаг уже стоит – сразу `"Отдых"`, функцию не зовите.
