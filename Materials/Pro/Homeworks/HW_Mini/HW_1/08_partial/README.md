#### **№8. Пресет. · 1 балл**

**1 балл.**

Каждый раз перед эфиром собирают карточку со служебной информацией: город, шоу и час. Собирает её `card(city, show, hour=0)`. Она возвращает строку `f"{city}: {show} ({hour})"`. Если час не передали, в строке будет `0`.

Город и шоу вечер за вечером одни и те же. Сегодня снова Москва и «ночь», другой только час. Писать `card("Москва", "ночь", 3)` каждый раз незачем: город и шоу уже известны.

Пресет – вызов, у которого эти аргументы уже стоят на местах. Напишите `partial(func, /, *args, **kwargs)`. Она запоминает их и возвращает короткий вызов.

```python
night = partial(card, "Москва", "ночь")
night()   # -> Москва: ночь (0)
night(3)  # -> Москва: ночь (3)
```

`partial` зовут сами и передают ей функцию первым аргументом, без имени. В примерах эта функция – `card`. Запомнить можно аргументы любой функции: и без имени, по порядку, и по имени параметра.

Напишите функцию самостоятельно. Использовать готовую `functools.partial` запрещено.

**Уточнения.**

- Функцию передают первой и без имени. Аргумент без имени встаёт в следующий параметр по порядку: `"Москва"` – это `city`. Аргумент по имени встаёт в параметр с этим именем: `show="Москва"` – это шоу, даже если написано раньше города.
- Сначала идут аргументы, которые запомнили, потом новые. Запомненный аргумент без имени новым аргументом без имени не затирается.
- Аргумент по имени из нового вызова заменяет запомненный аргумент с тем же именем. Новое имя добавляется, если такого ещё не было.
- Можно запомнить только имена, без остальных аргументов. Можно не запоминать ничего: новая функция просто откладывает вызов.
- Две заготовки одной функции друг друга не видят. `partial(card, "Москва")` не мешает `partial(card, "Казань")`.
- Исходная функция вызывается один раз за вызов. Если она вернула `None` или `0`, наружу идёт именно это.

**Примеры:**

```python
def card(city, show, hour=0):
    return f"{city}: {show} ({hour})"

night = partial(card, "Москва", "ночь")
night()          # -> Москва: ночь (0)
night(3)         # -> Москва: ночь (3)

partial(card)("Москва", "ночь", 3)       # -> Москва: ночь (3)
partial(card, "Москва")("ночь", 3)       # -> Москва: ночь (3)
partial(card, "Москва", "ночь")(hour=3)  # -> Москва: ночь (3)
partial(card, "Москва", "ночь", hour=1)(hour=3)  # -> Москва: ночь (3)
partial(card, hour=3)("Москва", "ночь")  # -> Москва: ночь (3)
```

```python
moscow = partial(card, "Москва")
kazan = partial(card, "Казань")
moscow("ночь", 1)  # -> Москва: ночь (1)
kazan("утро", 2)   # -> Казань: утро (2)
moscow("ночь", 1)  # -> Москва: ночь (1)
```

```python
def mute(city):
    return None

partial(mute, "Москва")()  # -> None
```

## **Как это сделать.**

`partial` возвращает внутреннюю функцию. Она помнит запомненные аргументы и один раз вызывает исходную: сначала запомненные аргументы без имени, потом новые. Аргумент по имени из нового вызова заменяет старый с тем же именем.
