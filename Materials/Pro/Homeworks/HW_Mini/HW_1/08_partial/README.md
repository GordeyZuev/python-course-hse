#### **№8. Пресет. · 1 балл**

**1 балл.**

Один и тот же вызов каждый раз начинается с одних и тех же аргументов. `partial` зажимает их заранее и возвращает новую функцию. Когда эту функцию зовут, она вызывает исходную: сначала то, что зажали, потом то, что передали сейчас.

`partial(func, /, *args, **kwargs)`

Это не `functools.partial`. Нужна своя функция. Тесты сравнивают объекты и не примут библиотечную.

Карточка в примерах устроена так: `card(city, show, hour=0)` возвращает `f"{city}: {show} ({hour})"`.

- Сначала идут зажатые позиционные, потом новые позиционные. Зажатый позиционный новым позиционным не затирается.
- Имя из вызова перекрывает зажатое имя с тем же ключом. Новое имя добавляется, если такого ключа ещё не было.
- Можно зажать только имена, без позиционных. Можно не зажать ничего: пресет просто откладывает вызов.
- Два пресета одной функции друг друга не видят.
- Исходная функция входит один раз за вызов пресета. Возврат `None` и `0` – обычный возврат, его не подменяют.

```python
def card(city, show, hour=0):
    return f"{city}: {show} ({hour})"

night = partial(card, "Москва", "ночь")
night()          # -> Москва: ночь (0)
night(3)         # -> Москва: ночь (3)

partial(card)("Москва", "ночь", 3)       # -> Москва: ночь (3)
partial(card, "Москва")("ночь", 3)       # -> Москва: ночь (3)
partial(card, "Москва", "ночь")(hour=3)  # -> Москва: ночь (3)
partial(card, "Москва", "ночь", hour=1)(hour=3)  # -> Москва: ночь (3)
partial(card, hour=3)("Москва", "ночь")  # -> Москва: ночь (3)
```

```python
moscow = partial(card, "Москва")
kazan = partial(card, "Казань")
moscow("ночь", 1)  # -> Москва: ночь (1)
kazan("утро", 2)   # -> Казань: утро (2)
moscow("ночь", 1)  # -> Москва: ночь (1)
```

```python
def mute(city):
    return None

partial(mute, "Москва")()  # -> None
```

## **Как это сделать.**

`partial` возвращает внутреннюю функцию. Она помнит зажатые аргументы. Новые имена перекрывают старые с тем же ключом.
