#### **№4. Польская запись. · 0.5 балла**

**0.5 балла.**

Есть выражение – оно записано списком в виде трёх значений: оператор и два операнда, `[оператор, слева, справа]`. Операнд – целое число или снова такой список. Напишите функцию `polish(expr)`. Она раскладывает выражение в прямую польскую запись: сначала оператор, потом левая часть, потом правая.

Это не обратная запись. Оператор стоит перед операндами, а не после них.

Функция возвращает строку. Число само по себе – уже готовый кусок: его строковое представление. Куски склеиваются одним пробелом, без пробела в начале и в конце. Число `0` и число из нескольких цифр остаются как есть.

```python
polish(4)                          # -> 4
polish(0)                          # -> 0
polish(["+", 2, 3])                # -> + 2 3
polish(["*", ["+", 2, 3], 4])      # -> * + 2 3 4
polish(["-", 8, ["/", 6, 2]])      # -> - 8 / 6 2
polish(["+", 10, 2])               # -> + 10 2
```

Мы работаем только с операторами: `"+"`, `"-"`, `"*"`, `"/"`.
Отрицательных чисел нет.

## **Как это сделать.**

Рекомендуем рекурсию: части выражения устроены так же, как целое выражение. Базовый случай – число: его сразу превращаете в строку. Для списка сначала берёте оператор, затем обрабатываете левую и правую части. Рекурсия здесь не обязательна: можно выбрать другой способ, который сохраняет порядок и формат результата.
