#### **№4. Польская запись. · 0.5 балла**

**0.5 балла.**

Выражение записано списком: оператор и два операнда, `[оператор, слева, справа]`. Операнд – целое число или снова такой список. `polish(expr)` раскладывает это в прямую польскую запись: сначала оператор, потом левая часть, потом правая.

Это не обратная запись. Оператор стоит перед операндами, а не после них.

Число само по себе – уже готовый кусок: его строка. Куски склеиваются одним пробелом, без пробела в начале и в конце. Число `0` и число из нескольких цифр остаются как есть.

```python
polish(4)                          # -> 4
polish(0)                          # -> 0
polish(["+", 2, 3])                # -> + 2 3
polish(["*", ["+", 2, 3], 4])      # -> * + 2 3 4
polish(["-", 8, ["/", 6, 2]])      # -> - 8 / 6 2
polish(["+", 10, 2])               # -> + 10 2
```

В тестах операторы – строки `"+"`, `"-"`, `"*"`, `"/"`. Отрицательных чисел нет.

## **Как это сделать.**

Раскладывайте выражение рекурсией. Дно – число: его сразу превращаете в строку. Список снова уходит в `polish` по своим частям.
