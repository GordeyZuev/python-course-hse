#### **№2. Не передали. · 0.5 балла**

**0.5 балла.**

`ask(answer)` возвращает то, что передали. Вызов без аргумента – не то же самое, что передать `None`.

`None` в значении по умолчанию их не различает: `None` уже ответ. Нужен свой маркер. До Python 3.15 его делают через `object()`. Что это за приём: [sentinel](https://docs-python.ru/tutorial/vstroennye-funktsii-interpretatora-python/klass-sentinel-unikalnoe-znachenie-marker/).

- Без аргумента верните `"не передали"`.
- `None`, `0`, `False`, `""` и любой другой переданный объект верните как есть. Список – тот же объект.

```python
ask()        # -> не передали
ask(None)    # -> None
ask(0)       # -> 0
ask(False)   # -> False
ask("")      # ->
ask("Аня")   # -> Аня
```

## **Как это сделать.**

Положите свой `object()` в значение по умолчанию. Сравнивайте аргумент с ним через `is`: так пропущенный вызов отделяется от переданного `None`.
