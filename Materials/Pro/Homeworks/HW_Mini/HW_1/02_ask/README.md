#### **№2. Не передали. · 0.5 балла**

**0.5 балла.**

Вам необходимо реализовать функцию `ask(answer)`, которая возвращает то, что в неё передали. Вызов без аргумента – не то же самое, что передать `None`. Именно для этого особого случая и существует задача.

`None` как значение по умолчанию не отличает пропущенный вызов от переданного `None`: `None` уже ответ. Нужен свой маркер. До Python 3.15 его делают через `object()`.

> Sentinel object – объект-маркер «сюда ничего не передали». Его узнают через `is`, а не через `==`: важен сам объект, а не похожее значение. Маркер нужен, когда `None` уже может быть настоящим ответом. [The Sentinel Object Pattern](https://python-patterns.guide/python/sentinel-object/).

- Без аргумента верните `"не передали"`.
- `None`, `0`, `False`, `""` и любой другой переданный объект верните как есть. Список – тот же объект.

```python
ask()        # -> не передали
ask(None)    # -> None
ask(0)       # -> 0
ask(False)   # -> False
ask("")      # ->
ask("Аня")   # -> Аня
```

## **Как это сделать.**

Создайте и положите свой `object()` в значение по умолчанию. Сравнивайте аргумент с ним через `is`: так пропущенный вызов отделяется от переданного `None`.
