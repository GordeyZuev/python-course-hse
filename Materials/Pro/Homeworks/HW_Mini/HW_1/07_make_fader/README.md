#### **№7. Фейдер. · 1 балл**

**1 балл.**

У канала на микшере свой ползунок громкости. Этот ползунок называют фейдером. Сдвинули его на `delta` – громкость этого канала изменилась. Соседний канал стоит на месте.

Напишите `make_fader(level)`. `level` – громкость, с которой ползунок начинает.

`make_fader(90)` возвращает сам ползунок. В примерах его называют `change`. Дальше двигают уже его: `change(20)` прибавляет 20 к 90. Выше 100 ползунок не идёт, поэтому наружу приходит `100`. Громкость помнится: следующий `change` идёт уже от нового уровня, а не снова от 90.

**Уточнения.**

- Диапазон – от 0 до 100 включительно. Числа целые. Стартовый `level` в тестах уже внутри этого диапазона.
- Ниже 0 не опуститься. Лишний шаг за границей не запоминается. После упора в 100 следующий `change(-5)` идёт от 100 и даёт `95`. После упора в 0 следующий положительный шаг идёт от 0.
- Шаг `0` оставляет уровень как есть.
- Ровно 0 и ровно 100 достижимы.
- `make_fader(10)` и `make_fader(50)` – два ползунка. Сдвиг левого не меняет правый.

**Примеры:**

```python
change = make_fader(90)
change(20)  # -> 100
change(5)   # -> 100
change(-5)  # -> 95

quiet = make_fader(10)
quiet(-40)  # -> 0
quiet(-3)   # -> 0
quiet(4)    # -> 4

left = make_fader(10)
right = make_fader(50)
left(5)     # -> 15
right(0)    # -> 50
```

## **Как это сделать.**

Громкость живёт в замыкании. `make_fader` создаёт `change`, и после возврата `change` всё ещё пишет в ту же громкость. В `change` напишите `nonlocal`, прибавьте `delta` и обрежьте результат до 0..100. Лишнее за границей в уровень не записывайте.
