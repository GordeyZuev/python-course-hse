#### **№7. Фейдер. · 1 балл**

**1 балл.**

У каждого канала свой фейдер. `make_fader(level)` возвращает `change(delta)`: сдвигает громкость и отдаёт то, что получилось. Громкость помнится после того, как `make_fader` уже вернулся. Это не имя модуля: два фейдера друг друга не видят.

Диапазон – от 0 до 100. Лишний шаг за границу не копится: следующий шаг идёт уже от упора. Шаг `0` оставляет уровень как есть.

Числа целые. Стартовый уровень в тестах уже внутри 0..100.

```python
change = make_fader(90)
change(20)  # -> 100
change(5)   # -> 100
change(-5)  # -> 95

quiet = make_fader(10)
quiet(-40)  # -> 0
quiet(-3)   # -> 0
quiet(4)    # -> 4

left = make_fader(10)
right = make_fader(50)
left(5)     # -> 15
right(0)    # -> 50
```

## **Как это сделать.**

Уровень живёт в `make_fader`, а `change` пишет в него через `nonlocal`. После сложения обрежьте значение до 0..100: шаг за упор не должен копиться.
