#### **№1. Эфирная строка. · 0.5 балла**

**0.5 балла.**

Диктор читает одну строку – название, потом артисты, потом год. Ваша задача – помочь диктору собрать эту самую строку, используя функцию `line(title, /, *artists, year=None)`.

**Правила, которые вам необходимо реализовать:**

- Если нет артистов и год не передан – верните только `title`. При пустом названии на выходе будет пустая строка.
- Артисты идут в переданном порядке через `", "`. Перед ними стоит `" - "`.
- Года нет, если его не передали или передали `year=None`: строка остаётся без года. Число `0` – год, не пустота: строка заканчивается на `" (0)"`.
- `title` должен передаваться исключительно позиционно. `year` – только по имени. Это задаётся через `/` и `*`: [Special parameters](https://docs.python.org/3/tutorial/controlflow.html#special-parameters). Самостоятельно ошибку не реализуйте.
- При пустом имени артиста – оставляем пустоту: `line("ночь", "")` даёт `"ночь - "`.

**Примеры:**

```python
line("ночь", "Аня", year=2000)       # -> ночь - Аня (2000)
line("ночь", "Аня", "Боря")          # -> ночь - Аня, Боря
line("ночь")                         # -> ночь
line("ночь", year=0)                 # -> ночь (0)
line("ночь", year=None)              # -> ночь
```

## **Как это сделать.**

Соберите одну строку в теле `line`, начиная с названия. Артистов дописывайте только если они есть, год – только если он не `None`.
