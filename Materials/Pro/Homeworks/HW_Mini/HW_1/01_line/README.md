#### **№1. Эфирная строка. · 0.5 балла**

**0.5 балла.**

Диктор читает одну строку: название, потом артисты, потом год. Соберите её.

`line(title, /, *artists, year=None)`

- Нет артистов и год не передан: верните сам `title`. Пустое название тоже: наружу выходит пустая строка.
- Артисты идут в переданном порядке через `", "`. Перед ними стоит `" - "`.
- Года нет, если его не передали или передали `year=None`. Число `0` – год, не пустота: строка заканчивается на `" (0)"`.
- `title` передаётся только позиционно. `year` – только по имени. Название по имени Python не примет: это устройство подписи, самим бросать ошибку не нужно. Как устроены `/` и `*`: [Special parameters](https://docs.python.org/3/tutorial/controlflow.html#special-parameters).
- Пустой артист остаётся в списке: `line("ночь", "")` даёт `"ночь - "`.

```python
line("ночь", "Аня", year=2000)       # -> ночь - Аня (2000)
line("ночь", "Аня", "Боря")          # -> ночь - Аня, Боря
line("ночь")                         # -> ночь
line("ночь", year=0)                 # -> ночь (0)
line("ночь", year=None)              # -> ночь
```

## **Как это сделать.**

Соберите одну строку в теле `line`, начиная с названия. Артистов дописывайте только если они есть, год – только если он не `None`.
