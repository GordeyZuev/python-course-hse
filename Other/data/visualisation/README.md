# Данные урока 06. Visualisation

Локальные снимки подготовлены 11 ноября 2026 года. В уроке CSV поездок читается напрямую по ссылке Seaborn, как в пятой паре; локальная копия сохранена для сверки. Географические границы читаются из подготовленного файла этого каталога.

- `taxis.csv`: неизменённая [выборка Seaborn](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/taxis.csv), 6433 строки. Это учебная выборка, не полный поток поездок.
- `taxi_zones.geojson`: производный файл из [официального архива TLC](https://d37ci6vzurychx.cloudfront.net/misc/taxi_zones.zip), указанного на [странице TLC](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page).

Исходные 263 геометрии в EPSG:2263 объединены по паре `borough`, `zone`: названия Corona и Governor's Island/Ellis Island/Liberty Island относятся к нескольким LocationID, а в CSV поездок идентификаторов нет. После объединения получено 260 уникальных пар. Для отображения границы упрощены с допуском 20 единиц исходной системы (футы США), с сохранением топологии отдельной геометрии, затем преобразованы в WGS 84 / EPSG:4326. `zone_id` — локальный ключ, не официальный LocationID. Данные предназначены для карты, не для измерения площадей или восстановления точных мест посадки. Версия границ не гарантирует историческую точность для 2019 года.

При соединении все непустые пары район/зона поездок сопоставлены; 26 строк имеют пропуски и не нанесены на карту. Отсутствие поездок в зоне означает отсутствие записей в выборке, а не нулевой спрос. Использование исходных данных регулируется условиями их поставщиков; отдельная новая лицензия на исходные данные здесь не заявляется.

## Свои данные

Примеры [урока 06](../../../Materials/Pro/06.%20Visualisation.ipynb) можно адаптировать под свой датасет: заменить загрузку, выбрать нужные столбцы и пересчитать показатели. Подписи, единицы измерения и группировки должны соответствовать новым данным. Для географических примеров нужны свои координаты или границы территорий и ключ, который связывает их с таблицей показателей; подложка карты эти сведения не заменяет.
