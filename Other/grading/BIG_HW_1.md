# Сдача Big HW 1

Работайте в своём приватном репозитории курса. Получите новые материалы по
[инструкции](UPDATES.md), откройте
`Materials/Pro/Homeworks/BIH_HW/HW_1/HW_1.ipynb` и решайте задачи в нём.
Сохраните код, опыты и выводы в этом же ноутбуке.
Перед отправкой запустите **Restart Kernel and Run All**. Проверить №1–11
локально можно командой `python Other/tools/grade.py --hw pro-big-hw1` из корня
репозитория в окружении с зависимостями из `homework.json`.

Когда готовы отправить работу:

```bash
git add Materials/Pro/Homeworks/BIH_HW/HW_1/HW_1.ipynb
git commit -m "Submit Big HW 1"
git push origin main
```

Push с изменением ноутбука запускает отдельную проверку Big HW 1 в **Actions**.
Откройте запуск **Submit pro-big-hw1** и его **Summary**. Там видны баллы за
№1–11 – максимум 5. Задачи №12–16 и бонус проверит ассистент после дедлайна.
После его проверки итог и баллы по всем задачам появятся в Issue
«Оценки и проверки» вашего репозитория.

Для Big HW 1 доступны **четыре попытки**. Локальные коммиты и получение
обновлений попытку не расходуют. Один push с изменением `HW_1.ipynb` расходует
одну попытку; другие ДЗ от этого не запускаются. Изменение выводов или
метаданных ноутбука тоже считается изменением файла. Дедлайн –
**29.11.26 23:59 (GMT+3)**. После него тесты ещё покажут результаты,
если попытки остались, но зачётный балл поздней сдачи будет **0**.
Своевременная сдача сохраняется. Если четвёртая попытка исчерпана или запуск
завис в очереди, свяжитесь с ассистентом.

Ассистент может изменить балл за любую задачу, включая №1–11, с объяснением.
Бонус за отзыв – отдельная задача до 0,2 балла. Общий максимум – 10,2.
