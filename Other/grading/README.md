# Сдача домашних работ

Каждому студенту выдаётся один приватный репозиторий на курс. Решения загружайте
в него, в `main`, сохраняя исходные пути файлов. Меняйте только файлы решений.
Тесты, условия и workflow поддерживают преподаватели.

Каждый push с изменёнными решениями — сдача соответствующего ДЗ целиком.
На каждое ДЗ четыре попытки. Push, затрагивающий два ДЗ, расходует по одной
попытке каждого. В зачёт идёт лучший общий результат одной попытки.
Не отправляйте промежуточные решения на GitHub, если не готовы тратить попытку:
локальные коммиты и тесты ограничений не имеют.

Сразу после push откройте Actions → Submit <код ДЗ> → Summary
(например, Submit pro-hw1).
Официальная ведомость и Issue «Оценки и проверки» обновляются раз в три часа,
иногда позднее из-за очереди GitHub. Срок определяется временем создания
запуска GitHub, не временем коммита и не временем обновления ведомости.
Проверка, принятая вовремя, может завершиться после дедлайна.

После дедлайна тесты также выполняются, если не исчерпаны четыре попытки.
Вы увидите результат каждой задачи, сумму за тесты и пометку «Сдано после
дедлайна». Зачётный балл этой попытки — **0 / 10**. Лучшая своевременная сдача
при этом сохраняется. Пятая и последующие попытки тесты не запускают.

Повторный запуск той же проверки не создаёт новую попытку. Не удаляйте и не
изменяйте workflow: такой результат не принимается. Удаление истории запусков
не возвращает попытки. При техническом сбое обратитесь к преподавателю.

## Обновление курса

Получайте сначала `origin/main` из своего приватного репозитория, затем
`upstream/course_2026` из общих материалов. Локальное получение обновлений
попытки не расходует. Начинайте новое ДЗ после завершения выдачи преподавателем.

[Пошаговая инструкция: настройка Git, обновления, отправка и разрешение конфликтов](UPDATES.md).
В ней также объясняется, почему push с ещё не отправленными решениями считается
сдачей, даже если последний коммит содержит только README.

## Локальная проверка

Из корня курса, в настроенном Python-окружении:

```bash
python Other/tools/grade.py --hw pro-hw1
python Other/tools/grade.py --hw pro-hw2
```

Для следующего ДЗ используйте его `id` из `homework.json` в аргументе `--hw`.
Без этого аргумента грейдер проверяет все включённые ДЗ.

После дедлайна ассистент проверяет зафиксированную лучшую сдачу и публикует
итог в Issue. Ручной итог имеет приоритет над автоматическим.

## Конфигурация задания

В папке ДЗ находится `homework.json`: в нём можно посмотреть дедлайн, задачи
и баллы. Этот файл поддерживает преподаватель. Его изменение в вашем репозитории
не меняет правила официальной проверки. Библиотеки из поля `dependencies`
установите в своё виртуальное окружение для локальных тестов.
